# Plant Defense: Nusantara Edition

Fondasi game Kivy 2D landscape: profil lokal, Petualangan, Survival, Mini Games, grid 5x9, kartu tanaman, surya, sekop, zombie, proyektil dan progres level tersimpan.

Build APK: GitHub Actions > Build Plant Defense APK > Run workflow. APK tersedia di artifact `plant-defense-debug-apk`.

Sprite dan audio buatan sendiri belum diintegrasikan; gameplay saat ini memakai bentuk sementara Kivy agar sistem inti dapat diuji lebih dahulu.
